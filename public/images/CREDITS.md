# Image credits

photos, no license required). Replace them with the business's real photos, keeping the same file
names, WebP format and sizes:

| File | Size | Use |
|---|---|---|
| `hero-detailing.webp` | 1200×900 | Hero image |
| `gallery-<id>-before.webp` / `gallery-<id>-after.webp` | 800×600 | Gallery before/after pairs (`id` from `GALLERY_ITEMS` in `src/data/detailingData.ts`) |
